# Project Summary: Network Incident Data Analysis

## Description
This project analyzes simulated network incident data inspired by network operations work. It focuses on firewall, VPN, routing, latency, packet loss, authentication, and application connectivity issues.

## Problem Statement
Network operations teams receive many incident tickets every day. Analyzing these tickets helps identify repeated issue categories, high-severity patterns, and operational bottlenecks.

## Approach
The dataset was loaded using Python and Pandas. Incident categories, severity levels, root causes, and resolution times were analyzed. Summary CSV files were generated to support reporting and portfolio presentation.

## Main Findings
- VPN, firewall, and authentication issues are important categories for operational review.
- Critical and high-severity incidents require longer resolution times.
- Root causes such as policy misconfiguration, authentication errors, expired certificates, and ACL conflicts can be monitored for prevention.
- This type of analysis can support automation, dashboard creation, and predictive incident management.

## Resume Description
Analyzed simulated firewall, VPN, and network incident logs using Python and Pandas to identify recurring issue categories, severity patterns, root causes, and resolution-time trends for operational troubleshooting.
